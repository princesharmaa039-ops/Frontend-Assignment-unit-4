# Advanced Student Dashboard

A React + Vite student dashboard with analytics, progress charts, activity timeline, and performance KPIs.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```

## Features

- Attendance, grades, and assignment metrics
- Student list with status badges
- Progress sparkline charts
- Daily activity feed and notifications
- Responsive dashboard layout
